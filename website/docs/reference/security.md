# 安全与隐私

只转存有权保存的内容。保留 Bot 私聊鉴权、管理员监听授权、来源访问核验、账号隔离和服务端拒绝处理。

## 凭据

不公开 Bot Token、API Hash、WebDAV 密码、网关授权、Session、数据库、真实配置或备份。Base64 不是加密。日志和报告必须脱敏；不加入遥测、埋点或凭据回传。

## 网络

管理端口默认限于回环或受控内部网络。公网使用 HTTPS；可信内网 HTTP 不做公网端口转发。手机只读入口使用独立账号与目录，不复用 Bot 写入账号。

## 维护边界

源码改名不授权接管其他项目、迁移用户数据、删除云端文件或操作生产主机。当前版本尚未发布，历史验收不替代本版验证。
