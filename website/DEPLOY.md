# TGCloud 文档站托管

当前只准备静态源码，没有部署生产站点。网站部署与 Bot 部署相互独立。

## 构建

使用 Node.js 22+，在 `website/` 执行 `npm run build`，输出为 `dist/`。托管完整项目时，根目录选择 `website`。本项目没有第三方 npm 依赖。

## 站点地址

确定真实生产域名后再设置 `SITE_URL` 为 HTTP(S) 源地址。当前留空，不沿用旧项目域名，也不虚构新域名。

## 发布边界

先通过 build 和 test，再由用户明确决定托管方式与发布。本文不创建站点、不上传产物、不触发云平台部署。
