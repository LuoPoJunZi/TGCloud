# TGCloud 备份和恢复

通过 `tgcloud` → 13. 数据备份管理核对覆盖范围。实例快照包含敏感配置和授权，仅保存在自己的受控目录，不上传公共仓库。

## 必须保护的数据

保留 SQLite 数据库及其一致性、Bot Session、个人监听 Session、`.env`、rclone 配置、CloudDrive2 授权和历史任务。TGCloud 的程序来源记录也应随备份保留。下载和云端对象按明确的备份范围处理，不能假定全部包含。

## 故障恢复

恢复前按[存储配置](configuration-guide.md)核对目录与凭据，按 [Bot 指南](bot-guide.md)确认任务状态。

升级前暂停新任务并等待活动传输结束。保留备份、日志和未核实的现场，按具体错误核对；不通过重建数据库或 Session 掩盖迁移。

隔离预检不等于生产恢复，也不代表云端内容哈希或最终入库已核实。未确定来源与归属的旧项目实例不自动恢复到新目录。
