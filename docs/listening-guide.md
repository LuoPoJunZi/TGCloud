# TGCloud 授权监听

监听默认关闭，必须由管理员显式授权。只监听当前账号能够访问且有权保存的来源，不增加绕过服务端限制的能力。

## 入口

使用 `tgcloud` → 16. 监听管理，在自己的私有终端登录个人账号；再通过 Bot 管理来源、筛选、命名、目录和计划。源码入口为 `python3 -B scripts/run_source.py listen --help`。

## 数据与故障

个人 Session 与 Bot Session 分开保存，不能公开、覆盖或在多个进程并发使用。停用保留来源、历史任务和授权文件。权限失效、限流或账号冷却须沿既有服务端拒绝和退让策略处理，不用删 Session 掩盖问题。
