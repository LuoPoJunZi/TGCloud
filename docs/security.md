# TGCloud 安全说明

## 授权与秘密

仅转存自己有权保存的内容。管理员和成员分别控制任务权限；个人监听账号需要单独授权，不能绕过 Telegram 服务端限制。

`.env`、API Hash、Bot Token、WebDAV 密码、Bot／个人 Session、数据库及备份都可能包含敏感信息。配置文件保持私有权限，Base64 不能替代加密。不要在公开 Issue、PR、截图或日志中暴露这些内容。

## 网络与容器

CloudDrive2 默认只在回环地址开放管理端口；公网使用 HTTPS 和适当认证。Bot 使用非 root、只读根文件系统和受限容器能力。CloudDrive2 挂载需要特权、`pid: host` 与 FUSE，应使用可接受相应隔离边界的主机。

外部只读访问使用独立账号与受限目录，确认权限后启用。密码轮换、共享代理和证书维护通过管理入口执行，不直接删除其他站点或容器。

## 来源和数据

安装、升级和卸载核验源码摘要、项目标记、容器及路径归属。未知目录、链接、异常挂载、其他数据库或来源变化都会停止处理。不要绕过检查，也不要手动修改来源记录使验证通过。

代码检查、合成回归与容器健康分别说明不同范围的结果。实际 Telegram 转存、云盘最终入库、公网证书和长期稳定性需要对应环境独立验证。
