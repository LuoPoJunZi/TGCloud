# TGCloud Bot 与任务

将有权保存的文件发送或转发到自己的私人 Bot。安装器与 Bot 共用当前 Python 核心，任务存入 SQLite，重启后沿既有状态恢复。

## 查看与管理

按 Bot 菜单查看任务、取消和失败恢复；常用功能优先使用按钮与逐项输入。宿主使用 `tgcloud` → 5. Bot 用户管理授权家人，8. 文件分类设置调整可选分类，11. WebDAV 验收独立检查目的端。

失败任务和不确定的远端现场按现有恢复规则保留。不要手工清空数据库、Session 或下载目录来消除报错，也不要在多个实例同时使用同一 Bot Token。

## 大文件

超过暂存预算的文件可使用流式管道。背压、资源窗口和磁盘保护仍有效；合成测试不能代表实际网速或长期吞吐。

## 原生命令菜单

```text
/status 查看系统状态
/queue 查看最近任务
/pause 暂停任务调度
/resume 恢复任务调度
/doctor 运行系统诊断
/orphans 检查临时文件
/help 查看使用帮助
```

管理员专用操作仍由权限检查控制，普通成员只能查看和操作自己的任务。

## 任务与恢复命令

| 命令 | 用途 |
| --- | --- |
| `/tasks` | 查看任务与操作入口 |
| `/task 编号` | 查看单个任务 |
| `/search 关键词` | 查找自己的任务 |
| `/cancel 编号` | 请求取消任务 |
| `/retry 编号` | 按当前失败状态重试 |
| `/restart 编号` | 从头重传，先确认处理范围 |
| `/recover 编号` | 保留原文件并换名恢复，须确认 |
| `/stream 编号` | 申请流式传输 |
| `/orphans` | 检查临时孤立文件，删除前须确认 |

先核对任务和云端现场，再选择恢复动作。不要通过反复重试绕过冲突检查。凭据和目标路径见[配置指南](configuration-guide.md)。

## 验收含义

网关接收和大小复验不代表内容哈希一致或云盘官方最终入库。首次使用先转存一个小文件并在官方客户端核对。
