## 本地私有资料

`archive/local/` 收纳已有本地审计、工作记录、构建证据和先前保存的材料，继续被 Git 忽略。没有将私有配置、账号、Session、数据库或备份公开，也没有删除原始资料。压缩归档内的原始字节作为历史证据保存，不作为当前构建输入。

新项目保留原许可证、版权和 TG115 上游致谢。Git 历史不重写，不以重命名伪造新的发布或验收。
